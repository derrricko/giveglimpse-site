WHAT THIS SITE
COLLECTS.

Almost nothing.

This site

giveglimpse.com is a static site. It has no accounts, no forms, no cookies set by Glimpse, and no analytics script. Nothing typed here is stored, because there is nowhere to type.

The site is hosted on GitHub Pages, which keeps standard server logs (IP address, browser, pages requested) under GitHub's privacy statement. Fonts load from Google Fonts, which receives the request under Google's privacy policy.

Links to other services

Pages link to X, pump.fun, Wikimedia Commons, and Paid. Following a link puts the visitor under that service's terms and privacy policy, not this one. Nothing from those services runs on this site until a link is clicked.

Video

Any video on this site is hosted here and served directly. No viewing data is collected.

Email

Messages sent to derrick@giveglimpse.com are kept as ordinary email and used only to reply.

Recipients and the record

The public record describes each undertaking, the spending, and what was delivered. It does not identify the people who receive help. Photos never show a recipient's face. Anyone named in the record (a participating business, for example) can ask for a correction at any time by email; entries are corrected, not removed.

Changes

This page changes when the site changes. The date at the top is the record.
